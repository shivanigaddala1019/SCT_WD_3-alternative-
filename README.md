# Tic-Tac-Toe Web Application

This project is created as part of SkillCraft Technology Web Development Internship – Task 3 (Alternative Project).

## Task Objective

Build a Tic-Tac-Toe web application that:

- Handles user clicks
- Tracks game state
- Checks winning conditions
- Creates an interactive game experience

## Features

✅ Player vs Player Mode  
✅ User Click Handling  
✅ Game State Tracking  
✅ Winner Detection  
✅ Draw Detection  
✅ Restart Game  
✅ Responsive Design  
✅ Interactive UI
